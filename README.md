# Tres Puntas

Blog personal sobre el motor rotativo de Mazda (RX-7, RX-8 y 787B), pensado para que cualquiera lo entienda sin saber de motores.

Incluye animaciones interactivas del motor, una comparación con el motor de pistón, las piezas, ventajas y problemas, una línea de tiempo y un quiz.

Es un sitio estático: solo `index.html` y la carpeta `img/`. Se publica con GitHub Pages.

En línea: https://sebasmartelo034.github.io/tres-puntas/
